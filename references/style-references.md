# Style References

Use these files when maintaining or extending the visual language for Cloudy Tech Diagrams.

## Reference Images

- `images/warm-template-preview.png` - Preview of the current warm HTML/SVG template direction.

## Maintenance Notes

Keep the skill's default output close to the warm editorial direction:

- Warm paper canvas instead of dark dashboards.
- Flat fills and thin strokes instead of shadows, glows, or gradients.
- Muted semantic colors with neutral space doing most of the work.
- Open chevron arrows instead of filled triangular arrowheads.
- Clear text hierarchy with Montserrat, Noto Sans SC, and system fallbacks.

The image in this directory is a repository-owned preview for maintainers and agents. Do not embed reference images in generated diagrams unless the user explicitly asks to use a specific image.
