# Draw.io fidelity through annotated SVG sheet

Cloudy Tech Diagrams treats **Draw.io Export Fidelity** as a product-critical contract, but keeps **Browser Visual Fidelity** as the entry-level product experience. We will pursue high-fidelity draw.io-native export from an annotated SVG sheet that contains the meaningful diagram content, including diagram-owned title, legend, caption, scope notes, and explanatory cards, while keeping page chrome, toolbar, and unrelated footer metadata outside the draw.io export. This chooses an annotated SVG sheet over full-page DOM conversion, draw.io-first generation, or one-image export because arbitrary HTML/CSS cannot be converted reliably into editable draw.io objects, draw.io-first generation would degrade the browser output, and one-image export would fail the editability goal.
