# Draw.io fidelity through annotated SVG sheet

Cloudy Tech Diagrams treats **Draw.io Export Fidelity** as a product-critical contract, but keeps **Browser Visual Fidelity** as the entry-level product experience. We will pursue high-fidelity draw.io-native export from an annotated SVG sheet that contains the meaningful diagram content, including any visible diagram legend or scope note, diagram-specific summary cards when they explain real context, and optional sheet-owned title or caption content when the exported sheet must stand alone, while keeping page chrome, toolbar, duplicate page title/subtitle, fixed template badges, and unrelated footer metadata outside the draw.io export. Legends and scope notes are not mandatory for every diagram, but when they appear as meaningful diagram content they must be represented in the Draw.io export. This chooses an annotated SVG sheet over full-page DOM conversion, draw.io-first generation, or one-image export because arbitrary HTML/CSS cannot be converted reliably into editable draw.io objects, draw.io-first generation would degrade the browser output, and one-image export would fail the editability goal.
