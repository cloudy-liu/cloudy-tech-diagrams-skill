Microservices Architecture

Kubernetes-orchestrated services behind one gateway with per-service data stores

Client Applications

  • React web app and mobile apps
  • Single public API surface

Microservices

  • Independent service ownership
  • Go, Java, and Python runtimes
  • Event bus for asynchronous coordination

Data Stores

  • Database per service
  • Search index for product discovery
  • Cluster boundary keeps ownership visible
