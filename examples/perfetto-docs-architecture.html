Perfetto Project Architecture

A homepage-style stack view of Perfetto's recording, analysis, and visualization capabilities, with a compact trace artifact flow across the three domains.

Record Traces

  • System, Chrome, and in-app tracing are shown as separate entry points.
  • The Track Event library and Tracing C++ library are shared recording foundations.
  • The output is a Perfetto protobuf trace artifact.

Analyze Traces

  • Trace Processor is the central analysis engine.
  • Importers normalize protobuf, JSON, systrace, and related formats.
  • SQL and metrics expose queryable analysis outputs.

Visualize Traces

  • Perfetto UI is the browser-based timeline surface.
  • Trace Processor WebAssembly supports local browser analysis.
  • WebUSB capture and offline use are first-class UI capabilities.
