Perfetto heapprofd Runtime Mechanism

A Cloudy-style redraw of the Perfetto heapprofd design diagram: sampled malloc stacks move through shared memory, remote unwinding, bookkeeping, and trace output.

Sampling Trigger

  • Tracing is enabled by property or signal
  • hprofd.so samples a percentage of malloc calls
  • Client work stays minimal inside the app process

Remote Unwinding

  • Sampled raw stacks cross through Shared Mem
  • heapprofd dispatches work to Unwind thread(s)
  • libunwindstack uses mmaps and ELF caches

Bookkeeping to Trace

  • Bookkeeping tracks live allocation tables
  • Symbol records retain frame context such as libart.so
  • heap dumps become observable perfetto trace output
